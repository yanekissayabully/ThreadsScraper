# Threads Scraper

Парсер постов из [Threads](https://www.threads.net) по ключевым словам. Поддерживает фильтрацию по дате и поиск из Казахстана.

Два скрипта на выбор — одиночный запрос и мультизапрос с объединением результатов.

---

## Файлы

| Файл | Описание |
|------|----------|
| `threads_scraper_single.py` | Поиск по одному ключевому слову |
| `threads_scraper.py` | Поиск по нескольким словам сразу, дедупликация |
| `requirements.txt` | Зависимости |
| `threads_cookies.json` | Куки сессии (создаётся автоматически, в `.gitignore`) |
| `results.json` | Результаты последнего запуска (создаётся автоматически) |

---

## Требования

- Python 3.9+
- Аккаунт в Threads (для авторизации)

---

## Установка

```bash
git clone https://github.com/your-username/threads-scraper
cd threads-scraper

pip install -r requirements.txt
playwright install chromium
```

## Первый запуск: сохранение куков

Threads требует авторизацию для доступа к поиску. Куки нужно сохранить один раз — они переиспользуются автоматически.

```bash
# Для одиночного скрипта
python threads_scraper_single.py --save-cookies

# Для мультизапросного скрипта
python threads_scraper.py --save-cookies
```

Откроется браузер — залогиньтесь в Threads вручную, затем вернитесь в консоль и нажмите **Enter**. Куки сохранятся в `threads_cookies.json`.

> **Куки действуют несколько недель.** Если скрипт начнёт возвращать пустые результаты — повторите шаг сохранения.

## Использование

### Одиночный запрос — `threads_scraper_single.py`

Ищет посты по одному ключевому слову.

```bash
python threads_scraper_single.py
```

Ключевое слово задаётся в начале файла:

```python
KEYWORD  = "амо срм"   # поисковый запрос
DAYS_BACK = 7          # максимальный возраст поста в днях
MAX_RESULTS = 100      # лимит постов
```

Или через аргументы:

```bash
python threads_scraper_single.py --days 3
python threads_scraper_single.py --days 14 --max 50
```

---

### Мультизапрос — `threads_scraper.py`

Ищет по нескольким ключевым словам последовательно, объединяет результаты и удаляет дубли.

```bash
python threads_scraper.py
```

Запросы задаются в начале файла:

```python
KEYWORDS = [
    "амо срм",
    "amocrm",
    "амосрм",
]
DAYS_BACK = 7
MAX_RESULTS = 100
```

Или через аргументы:

```bash
python threads_scraper.py --days 3
python threads_scraper.py --days 14 --max 50
```

## Результат

Оба скрипта выводят результаты в консоль и сохраняют в `results.json`.

**Консоль:**
```
[1] @username  •  27.05.2025 14:33  •  💬 12
     Интересный пост про AmoCRM...
     🔗 https://www.threads.net/@username/post/ABC123
```

**results.json:**
```json
[
  {
    "text": "Интересный пост про AmoCRM...",
    "published_on": "27.05.2025 14:33",
    "username": "username",
    "reply_count": 12,
    "url": "https://www.threads.net/@username/post/ABC123"
  }
]
```

Дата и время публикации указываются по часовому поясу **Алматы (UTC+5)**.

## Параметры запуска

| Аргумент | Описание | По умолчанию |
|----------|----------|-------------|
| `--days N` | Максимальный возраст поста в днях | `7` |
| `--max N` | Лимит постов на один запрос | `100` |
| `--save-cookies` | Сохранить куки браузера (первый запуск) | — |

---

## Как это работает

1. Playwright открывает Chromium с сохранёнными куками и переходит на `threads.net/search?q=...`
2. Параллельно перехватываются XHR-ответы от GraphQL и парсится скрытый JSON со страницы (`<script data-sjs>`)
3. Страница прокручивается вниз несколько раз для подгрузки дополнительных постов
4. Посты фильтруются по дате, дедуплицируются по URL и сортируются от свежих к старым

## Ограничения

- Поиск возвращает около 10–50 постов на запрос в зависимости от популярности темы
- Threads не предоставляет официального публичного API для поиска
- Геофильтрация по Казахстану не поддерживается на уровне Threads — скрипт использует локаль `ru-KZ` и часовой пояс `Asia/Almaty`
- При частых запусках рекомендуется использовать дополнительный аккаунт
